# Crocs Visualizer (Beta)

> **Disclaimer:** This is an independent, non-commercial portfolio and educational project. It is **not affiliated with, endorsed by, or sponsored by Crocs, Inc.** All trademarks belong to Crocs, Inc. Items shown do not guarantee in-store retail availability.

An interactive, responsive 2D bird's-eye view customizer for a pair of Classic Crocs. Users can customize colors and sizes (Infant to Adult), browse and semantically search Jibbitz charms, drag and drop charms onto 26 vent holes, rotate placed charms, and delete them with a deliberate 3-click interaction.

---

## Features

- **Side-by-Side Pair View:** Left and right Classic Crocs with 26 authentic vent holes (13 per shoe).
- **Responsive Jibbitz Panel:** Desktop sidebar or mobile bottom sheet drawer.
- **Semantic Vector Search:** Find charms by mood, style, or description using client-side vector search.
- **Interactive Charm Placement:** Touch-friendly drag-and-drop, magnetic snapping, and $360^\circ$ rotation.
- **Deliberate Deletion:** 1-click select + double-tap to delete prevents accidental removal.
- **Zero-Account Privacy:** Designs are saved directly to `localStorage`.
- **PNG Snapshot Export:** Export your custom Crocs with non-commercial disclaimers included.
